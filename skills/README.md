# ZOOL agent skills

This directory contains installation guidance for AI coding agents such as Claude
Code and Codex. `zool-install` covers installing, upgrading and rolling back ZOOL
on Komari and Nezha, including backups and verification.

For Claude Code, copy `skills/zool-install` into `~/.claude/skills/` for personal
use, or into your project's `.claude/skills/` directory. Then invoke `/zool-install`
or ask the agent to install, upgrade or roll back the ZOOL theme.

Alternatively, ask your agent to read and follow the
[raw installation skill](https://raw.githubusercontent.com/foru17/zool-theme/main/skills/zool-install/SKILL.md).
